01 / Overview

Big structural edits.
Unrelated content preserved.

Inversion-free editors keep the source well but can leave it unmoved. UltraEdit treats the edited region and its surroundings differently. Inside an attention-selected region, the source and target copies start from pure noise and follow an SDE reference path with a matching posterior update, so the layout can change. Outside, editing starts later with fresh reference noise and Euler steps, so the scene stays put. Source anchoring then shares the source's keys and values and scales the edit back wherever the two copies already agree. No training, no inversion, one trajectory.

03 / Method

Edit where it matters.
Anchor the rest.

UltraEdit runs a source copy and a target copy side by side and carries the edit as their displacement D. Spatially adaptive coupling gives every token its own start time, reference path and update rule. Source anchoring uses the source copy that the coupling already computes.

Adaptive coupling. Inside the attention region the paired inputs start from pure noise, the source follows a forward SDE path and the displacement takes the posterior step; outside, editing starts later with fresh reference noise and the Euler step.

The update, per token

Z_t^src = μ ⊙ Z_t^(src,fw) + (1 − μ) ⊙ [(1 − t) X^src + t ε_t], Z_t^tar = Z_t^src + D_t
D_t' = 1[t ≤ τ] ⊙ { μ ⊙ (a_t D_t + b_t Δx̂_t) + (1 − μ) ⊙ [ (t'/t) D_t + (1 − t'/t) Δx̂_t ] }
μ: attention region (SDE + Posterior) 1 − μ: the rest (Fresh Noise + Euler) τ: per-token start time Δx_t: target − source clean estimate

01Coupling

Attention-adaptive region

FLUX's own attention to the subject and edit words selects μ before any editing step. No external segmenter.

02Coupling

SDE + Posterior inside

Tokens in μ start from pure noise. The source follows a forward SDE path; the displacement takes the matching posterior step, so the layout is free to change.

03Coupling

Fresh Noise + Euler outside

The rest starts later from freshly noised source states and takes Euler steps, which keeps the scene where it was.

04Coupling

The region expands

While the layout forms, tokens the target attends to join μ and start editing at the next step, making room for spread wings or a raised arm.

05Anchoring

Shared keys and values

Target queries attend to the source copy's keys and values in selected layers, carrying over identity and appearance.

06Anchoring

Scaling back the edit where the copies agree

Once μ is fixed, a single step D ← (1 − ω) D moves tokens whose source and target estimates agree most of the way back toward the source.
